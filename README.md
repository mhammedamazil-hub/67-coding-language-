# 67

**67 is a programming language whose source alphabet contains only two symbols:
`6` (binary `0`) and `7` (binary `1`).**

A complete program is a continuous 6/7 stream — no keywords, no quotes, no
spaces, no punctuation. The stream is decoded into bytes (eight symbols per
byte, most significant bit first) and parsed as a real, deterministic binary
module format with a header, constant pool, function table and length-prefixed
instruction records. It is not a visual character replacement of a readable
language: the binary decoder rejects everything but `6` and `7`, and the
compiler pipeline is `decoder → parser → semantic verifier → safe stack
runtime`.

## The 6/7 number system

| stream | bits | decimal |
| ------ | ---- | ------- |
| `6`    | 0    | 0 |
| `7`    | 1    | 1 |
| `67`   | 01   | 1 |
| `76`   | 10   | 2 |
| `77`   | 11   | 3 |
| `7667` | 1001 | 9 |

Utilities (`src/lang/bits.ts`): stream↔bytes, stream↔BigInt, UTF-8 text↔67,
soft-wrap for display, and bit-offset to visual line/column. Every conversion
uses BigInt and is round-trip tested.

## Binary module format (v1)

All integers are big-endian; every section is length-prefixed:

```
magic            36 37 01 00        ('6','7', major 1, minor 0)
u32 constantCount; Constant[constantCount]
u32 importCount;   Import[]         (u32 module-name constant index)
u32 exportCount;   Export[]         (u32 name const, u32 slot)
u32 functionCount; Function[]       (function 0 = module initializer)

Constant: u8 tag
  01 INT:    u8 sign (0 zero | 1 pos | 2 neg), u32 magLen, big-endian magnitude
  02 FLOAT:  8 bytes IEEE-754 double
  03 STRING: u32 utf8Len, UTF-8 bytes

Function: u32 nameConst, u32 paramCount + name constants, u32 localCount,
          u32 codeLen + code, u32 tryCount + regions, u32 debugCount + entries
```

Instructions are a one-byte opcode plus fixed operands (`u8`/`u16`/`u32`) or
length-prefixed tables. The language covers numbers (BigInt integers and
floats), negatives, strings, booleans, null, arrays, objects, variables,
closures with upvalues, first-class/anonymous/recursive functions, classes
with constructors/methods/`this`/inheritance/`super`, exceptions
(try/catch/finally/throw), and cross-file modules with named imports/exports.
A semantic verifier walks the control-flow graph checking constants, locals,
function indices, jump targets, try regions and stack depth before execution.

## Safe runtime

Programs manipulate only explicit runtime values (`NumV`, `StrV`, `BoolV`,
`NullV`, `ArrV`, `ObjV`, `FnV`, `ClassV`, `InstV`, `ErrV`, `ModuleV`). The
runtime never exposes `window`, `document`, `localStorage`, `fetch`, the
filesystem or any host object; the only host contact is an injected `input`
callback. Limits: 10M instructions, 200 call depth, 1 MiB output/string cap,
100k array/object size cap, power-exponent cap, plus abort/timeout support.
Errors carry bit offsets and call stacks. No `eval`, no `new Function`.

## Workstation UI

A minimal, dark, monospace compiler workstation: file sidebar (virtual
IndexedDB/localStorage project filesystem), a binary editor showing only 6/7
source with bit-offset gutter and invalid-symbol diagnostics, a Run/Stop
terminal with stdout/stderr tabs, an instruction inspector (opcodes, operands,
constant pool — readable content kept in a side panel, never replacing the
binary source), docs, settings (wrap width, font size), search/replace,
copy/download/import/export of `.67` files and whole projects, and 25
generated examples (10 beginner, 10 intermediate, 5 advanced). Everything is
client-side and works offline via a service worker.

## Develop

```bash
npm install
npm test        # 78 tests: decoder, numbers, compiler, runtime, security, examples
npm run check   # TypeScript
npm run build   # Vite production build into dist/ (static, deployable to GitHub Pages)
npm run dev     # local dev server
```

The project deploys to GitHub Pages via `.github/workflows/pages.yml`
(install → test → type-check → build → deploy; set the repository Pages
source to **GitHub Actions**).
